HUONG DAN CHAY WEBSITE KKSHOP CHO CHU SHOP
==========================================

1. Cach mo website
------------------
- Bam dup file START_KKSHOP.bat de mo website.
- Website se tu mo trinh duyet tai dia chi:
  http://localhost:5000

2. Luu y khi dang su dung
-------------------------
- Khong dong cua so den khi dang dung website.
- Cua so den la chuong trinh dang chay website.
- Neu dong cua so den thi website se tat.

3. Cach tat website
-------------------
- Quay lai cua so den dang chay website.
- Bam Ctrl+C, sau do chon Y neu duoc hoi.
- Hoac dong truc tiep cua so den.

4. Neu bao cong 5000 dang ban
-----------------------------
- Thong bao nay thuong xay ra khi website KKSHOP da chay tu truoc.
- Chon Y de tat phien ban cu va chay lai.
- Chon N neu khong muon tat phien ban cu.

5. Neu bao loi database
-----------------------
- Chup anh man hinh loi trong cua so den.
- Gui anh cho ky thuat de kiem tra SQL Server/database.

6. Neu bao loi restore/build/chay web
-------------------------------------
- Chup anh man hinh loi trong cua so den.
- Gui anh cho ky thuat.

7. File danh cho ky thuat/dev
-----------------------------
- START_KKSHOP_DEV.bat dung de chay web truc tiep va xem log day du.
- Chu shop chi can dung START_KKSHOP.bat.
